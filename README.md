# Fuse for MorphOS

MorphOS port of **Fuse — the Free Unix Spectrum Emulator**, based on Fuse 1.9.2.

This port provides a native MorphOS user interface and video backends, with support for **Surface**, **Overlay** and **TinyGL** rendering.

## Highlights

- Native MorphOS/MUI interface
- Surface, Overlay and TinyGL video drivers
- Fullscreen mode using a dedicated MorphOS screen
- Fullscreen window covers the complete screen while preserving the emulator aspect ratio
- Surface fullscreen resolution follows the active scaler/filter output size
- Overlay and TinyGL fullscreen use the Ambient display mode
- Altivec-enabled build
- MorphOS locale.library
- Polish translation included in ISO-8859-2
- Program-local catalogs supported through `PROGDIR:Catalogs/`

MorphOS port of **Fuse — the Free Unix Spectrum Emulator**, based on Fuse 1.9.2.

This port provides a native MorphOS user interface and video backends, with support for **Surface**, **Overlay** and **TinyGL** rendering.

## Highlights

- Native MorphOS/MUI interface
- Surface, Overlay and TinyGL video drivers
- Fullscreen mode using a dedicated MorphOS screen
- Fullscreen window covers the complete screen while preserving the emulator aspect ratio
- Surface fullscreen resolution follows the active scaler/filter output size
- Overlay and TinyGL fullscreen use the Ambient display mode
- Altivec-enabled build
- MorphOS locale.library / CatComp localization support
- Polish translation included in ISO-8859-2
- Program-local catalogs supported through `PROGDIR:Catalogs/`
- Native MorphOS application icon
- Ready-to-use `Fuse.lha` package target
- Separate unstripped `Fuse.db` and stripped release `Fuse` binaries

## Requirements

- **MorphOS 3.18 or newer**

## Distribution

The release archive is designed to be self-contained. After extracting `Fuse.lha`, the emulator can be started directly from its directory without installing additional program files into the system.


ROMs, fonts, GUI resources and localization files required by the MorphOS port are included in the package.

## Localization

Translation sources are included with the distribution:

- `Catalogs/Fuse.cd` — catalog description
- `Catalogs/polski/Fuse.ct` — Polish translation

This makes it straightforward to add additional MorphOS translations.

## Author

MorphOS port maintained by **Michal Zukowski**.

Fuse itself is an open-source ZX Spectrum emulator developed by the Fuse project and its contributors.
